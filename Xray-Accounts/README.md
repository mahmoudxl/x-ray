# إدارة عيادة العظام — Android

تطبيق Android عربي يعمل محلياً دون اتصال بالإنترنت. النسخة الأولية تشمل:
- تسجيل دخول مدير وسكرتير (بيانات الدخول الأولية: `manager / 1234` و`secretary / 1234`).
- ملفات المرضى والبحث والتعديل والحذف.
- زيارات كشف/استشارة/متابعة مع سعر ومدفوع ومتأخر.
- سجل الزيارات وتعديلها وحذفها وطباعة الإيصال عبر خدمة الطباعة في Android.
- ملخصات وتقارير الإيرادات اليومية والشهرية.
- إعداد أسعار الخدمات، تغيير كلمات المرور، ونسخ/استعادة قاعدة البيانات.

## بناء APK
ارفع محتويات المشروع إلى مستودع GitHub، ثم افتح Actions وشغّل `Build Android APK` (أو ادفع إلى فرع `main`). بعد نجاح البناء نزّل artifact باسم `orthopedic-clinic-apk`.

## تنبيه أمني وتشغيلي
هذه نسخة أولية للاختبار وليست نظاماً طبياً معتمداً. بيانات المرضى تُحفظ محلياً في قاعدة بيانات التطبيق، والنسخة الاحتياطية ملف قاعدة بيانات غير مشفر؛ خزّنها في مكان آمن، ولا تستخدم بيانات مرضى حقيقية قبل مراجعة متطلبات الخصوصية والحماية. غيّر كلمات المرور الافتراضية فور أول دخول. يُنصح باختبار الاستعادة والطباعة على الجهاز المستهدف قبل التشغيل الفعلي.
