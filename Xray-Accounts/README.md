# حسابات الأشعة | Xray Accounts

تطبيق Android عربي لإدارة حسابات الأشعة — تصميم وتطوير **محمود سليمان**.

## المزايا
- قوائم الأماكن والملاحظات مطابقة للقوائم المنسدلة في ملف Excel.
- شهر مستقل وأرشيف للشهور السابقة.
- تصفية حسب المكان.
- إضافة وتعديل وحذف العمليات.
- حساب الإجمالي والمسحوبات والمتبقي.
- طباعة التقارير إلى PDF من قائمة الطباعة في أندرويد.
- تصدير واستيراد نسخة احتياطية JSON.
- حفظ محلي على الجهاز باستخدام WebView LocalStorage.

## بناء APK من GitHub
1. أنشئ مستودعًا جديدًا باسم `Xray-Accounts`.
2. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح تبويب **Actions** ووافق على تشغيل GitHub Actions إذا طُلب ذلك.
4. اختر سير العمل **Build Xray Accounts APK** ثم **Run workflow**، أو انتظر انتهاء البناء بعد رفع الملفات.
5. افتح عملية التشغيل الناجحة، ثم قسم **Artifacts**، وحمّل `Xray-Accounts-debug-apk`.
6. فك ضغط ملف Artifact وستجد `app-debug.apk` لتثبيته على هاتف أندرويد.

## فتحه في Android Studio
افتح مجلد المشروع هذا مباشرة في Android Studio، وانتظر Gradle Sync، ثم اختر Build > Build APK(s).

## ملاحظات مهمة
- هذه نسخة Debug للتجربة. إصدار التوزيع العام يحتاج توقيع Release بمفتاح خاص تحفظه بأمان.
- البيانات محفوظة محليًا داخل التطبيق؛ لا تمسح بيانات التطبيق أو تحذفه قبل تصدير نسخة احتياطية.
- اختبر أولًا ببيانات تجريبية وتأكد من PDF والنسخ الاحتياطي والاستعادة قبل الاعتماد الفعلي.
